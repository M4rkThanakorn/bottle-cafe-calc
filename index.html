เชื่อมต่อฐานข้อมูล Google Sheets

วางลิงก์ Web App URL ที่ได้จากการ Deploy Google Apps Script เพื่อบันทึกและดึงข้อมูลข้ามอุปกรณ์ได้แบบ Real-time

* หากไม่ได้ใส่ URL ระบบจะทำงานในโหมด Local Storage (เก็บข้อมูลในเบราว์เซอร์เครื่องนี้) ให้ใช้งานได้ทันที

1 โค้ดสำหรับ Google Apps Script (ฐานข้อมูล)

  1. สร้างไฟล์ Google Sheets ใหม่ ตั้งชื่อชีตด้านล่างว่า Records
  2. ไปที่เมนูด้านบนเลือก ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดด้านล่างนี้ลงไป กดปุ่ม บันทึก (Save)
  4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)
  5. เลือกประเภทเป็น เว็บแอป (Web app) > ผู้มีสิทธิ์เข้าถึงเลือก ทุกคน (Anyone) > กด Deploy
  6. คัดลอก Web app URL มาวางในช่องด้านบนสุดของหน้านี้

2 วิธีนำเว็บไซต์ขึ้น GitHub Pages (ใช้งานฟรีตลอดชีพ)

ขั้นตอนที่ 1: สร้าง Repository บน GitHub

ล็อกอินเข้าเว็บ github.com กดปุ่ม New ตั้งชื่อโปรเจกต์ เช่น bottle-cafe-calc เลือกเป็น Public แล้วกด Create repository

ขั้นตอนที่ 2: อัปโหลดไฟล์ index.html

บันทึกโค้ดหน้าเว็บนี้เป็นชื่อไฟล์ index.html จากนั้นกด Add file > Upload files บน GitHub ลากไฟล์ลงไปแล้วกด Commit changes

ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages

เข้าไปที่แท็บ Settings > Pages เลือก Branch เป็น main แล้วกด Save รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์สำหรับเปิดใช้งานบนมือถือและคอมพิวเตอร์ของร้านทันที
